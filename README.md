# NEXER #22641 Website

A close, responsive recreation of the team's Wix site using plain HTML, CSS, and JavaScript.

## Run locally

You can open `index.html` directly, or serve the folder for the best experience:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` - home page
- `awards.html`, `members.html`, `members-group.html`, `robots.html`, `sponsors.html` - inner pages
- `styles.css` - Wix-matched responsive layout and styling
- `app.js` - shared navigation, footer, page data, and season switchers
- `assets/backgrounds/` - season and page backgrounds
- `assets/branding/` - NEXER logo and favicon
- `assets/members/` - original and normalized member portraits
- `assets/awards/` - award-event photos
- `assets/robots/` - robot images
- `assets/sponsors/` - sponsor and partner logos
- `assets/fonts/` - local Montserrat font files
